# Pacote de Handoff — conteúdo padrão de `06-handoff/`

> Contrato entre a Product Machine e a Techmachine. Combinar mudanças com o sócio antes de alterar.

```
06-handoff/
├─ LEIA-ME.md              ← resumo do projeto, decisões e links para o resto
├─ prd.md                  ← problema, objetivos, usuários, escopo Fase 1, fora de escopo, métricas
├─ backlog.md              ← histórias com critérios de aceite, prioridade e estimativa
├─ capacidades.md          ← matriz de capacidades (hardware/SDK/API) e mapeamento tela → endpoint
├─ arquitetura.md          ← stack, integrações, hardware escolhido, infraestrutura e custos de nuvem
├─ design-system/          ← tokens e componentes tematizados
├─ prototipo/              ← código do protótipo Hi-Fi aprovado
├─ teste-usabilidade.md    ← o que foi testado, problemas e ajustes feitos
└─ pendencias.md           ← o que ainda está aberto e quem decide
```

## LEIA-ME.md deve conter
- Trilha, cliente, data do contrato/aprovação.
- Link para cada decisão de gate (`projeto.md`).
- Prazo e marcos combinados.
- Contato do lado do cliente (se houver).
