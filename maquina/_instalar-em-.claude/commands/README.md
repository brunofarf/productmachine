# Commands

| Command | What it does |
|---|---|
| `/novo-projeto [nome]` | Asks the track, creates the project folder from the template, adds the row to `STATUS.md`, runs the interview, then continues the track. |
| `/importar [nome]` | Starts a project from material that already exists; fills the stage files and lists the gaps. |
| `/retomar <projeto>` | Runs the track from the current stage until the next human gate or human task. |
| `/aprovar <projeto> [decisão]` | Records the gate decision (approve / adjust / pivot / kill) and resumes. |
| `/status` | What is waiting for Bruno and what can run now. |
| `/encerrar <projeto> [concluido \| arquivar]` | Closes or archives a project, updates the knowledge base, proposes overrides to promote. |
