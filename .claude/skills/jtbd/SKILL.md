# Jobs-to-be-Done

## Steps
1. **Main job** — in the form *verb + object + context* (e.g. "saber onde está cada ônibus durante o turno"). One main job per segment.
2. **Job map** — break it into steps: define → locate inputs → prepare → confirm → execute → monitor → modify → conclude. Note where each step fails today.
3. **Related jobs** — functional, social (how they want to be seen) and emotional (how they want to feel).
4. **Desired outcomes** — measurable statements: *minimizar/aumentar + métrica + objeto* (e.g. "minimizar o tempo para descobrir um atraso"). Rate importance and current satisfaction (1–5) when evidence allows; opportunity = importance + max(importance − satisfaction, 0).
5. **Hiring/firing** — what they "hire" today, and what would make them "fire" it.

Mark ratings without evidence as **PREMISSA**.
