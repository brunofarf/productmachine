# Value Proposition Canvas

## Customer profile (from JTBD and research)
- **Jobs** — functional, social, emotional.
- **Pains** — risks, obstacles, frustrations, costs. Rank by severity.
- **Gains** — required, expected, desired, unexpected outcomes.

## Value map
- **Products & services** — what we deliver (software, hardware bought off-the-shelf, service).
- **Pain relievers** — exactly which pain each one removes or reduces.
- **Gain creators** — which gain each one produces, quantified when possible.

## Fit check
| Dor / ganho (ranking) | Aliviador / criador | Funcionalidade | Prova (como vamos demonstrar) |
|---|---|---|---|
Every top-3 pain must have a reliever; a relieved pain with no proof is a **PREMISSA**.

## One sentence (PT-BR)
> Para **[ICP]**, que **[dor principal]**, o **[produto]** **[faz o quê]**, diferente de **[alternativa atual]**, **[diferença mensurável]**.

Also write the form-friendly hint: *o que fazemos + para quem + qual problema resolvemos + por que somos 10x melhores que as alternativas*.
